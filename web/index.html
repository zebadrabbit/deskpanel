deskpanel

An always-on homelab status screen. Connect, flash, go.

1Connect & flash

  • The board: Waveshare ESP32-S3-Touch-LCD-4.3B (the B variant; other boards won't work).
  • A USB-C data cable (some cables only charge) and Chrome or Edge on a computer.
  1. Plug the board's USB-C port into this computer.
  2. Click Connect & flash and pick the port named USB JTAG/serial debug unit.
  3. Click Install deskpanel. It erases the board, then writes the firmware: about two minutes.
This browser can't reach USB serial ports. Open this page in Chrome or Edge on a computer, or flash from the command line (below).
Flashing in the browser needs this page on https:// or http://localhost. Or flash from the command line (below).
It doesn't connect, or the port isn't in the list
  • Try another cable or USB port. A charge-only cable shows no port at all.
  • Download mode: hold the board's BOOT button, tap RESET, let go of BOOT, then click Connect again. After flashing, tap RESET once to start the new firmware.
  • Linux: your user needs the serial group: sudo usermod -aG dialout $USER (Arch: uucp), then log out and back in.
  • Close anything else using the port (a serial monitor, another flasher tab).
No Chrome or Edge? Flash from the command line

Download the firmware image, then, with Python's esptool (pip install esptool):

esptool.py --chip esp32s3 write_flash 0x0 deskpanel-<version>.bin

One image for offset 0: bootloader, partition table and app. If it can't connect, use download mode (above).

2Make your settings.txt

The panel reads its Wi-Fi, server address, token and time zone from settings.txt on its microSD card.

2.4 GHz only: the panel can't see 5 GHz networks.
That machine's LAN address and port 8088. Plain http://.
A new random one, or the PANEL_TOKEN from your aggregator's .env. Step 3 uses the same.
The second column of this list.
More: time server
The file is made right here in your browser. Nothing you type is sent anywhere: this page has no server to send it to.

Then

  1. Copy it to the top folder of a microSD card formatted FAT32 (most cards up to 32 GB come that way). The name must be exactly settings.txt: not settings (1).txt, not settings.txt.txt.
  2. Card into the panel, tap RESET (or unplug it and plug it back in). It reads the file once, at boot.
  3. The Wi-Fi icon turns green. Until the server runs, the panel shows Waiting for the aggregator…

Change something later? Edit the file on the card and restart the panel. Every key and rule: the README.

3Start the server

A small Go service on any Linux machine with Docker (amd64 or arm64: a Raspberry Pi 4 or 5 with a 64-bit OS is fine). It makes every API call and hands the panel one compact document.

The token below is the one in the form above. Use the PANEL_TOKEN line of the settings.txt you downloaded: reloading this page makes a new token.

Just try it: fake data, nothing to set up

docker run -d --name deskpanel --restart unless-stopped -p 8088:8088 \
  -e DEMO=1 -e PANEL_TOKEN=… -e TZ=America/Chicago \
  ghcr.io/zebadrabbit/deskpanel-aggregator

For real: your GPUs, pools, services, task boards, weather

git clone https://github.com/zebadrabbit/deskpanel
cd deskpanel/aggregator
cp .env.example .env
# in .env set PANEL_TOKEN=…
#             LISTEN=192.168.0.20:8088  TZ=America/Chicago
# then the URL of each source you have; leave the rest empty
docker compose -f compose.image.yaml up -d

Within a few seconds the panel fills in. Each source is explained in aggregator/README.md; if the panel says NO DATA or STALE, see When something looks wrong.

Try the screen editor

Once the server runs, you can lay out your tabs in a browser instead of editing layout.json by hand. Open the demo: the same page, with made-up data. Nothing is saved; Download layout.json gives you the file. How to turn it on for your own server is in the README ("Edit your tabs in the browser?").
